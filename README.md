# RFID

Repositorio para el TFG de Álvaro Hugo Hernández Triana

Esta compuesto de:

lector_rfid.py -> Emula el lector de tarjetas

server_rfid.py -> Servidor

webclient_rfid_v6.html -> Representa el código fuente html del cliente web. Para usarlo solo lo tenemos que seleccionar y que se abra en nuestro explorador

No se adjuntan en la solución los JSON, ya que los crea automáticamente el código. Eso si si queremos dar de alta usuarios, tendremos que darlos de alta accediendo al cliente web y dandolos de alta
